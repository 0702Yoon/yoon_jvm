# 런타임 메모리 구조

---

### 서론

C,C++은 메모리 관리를 개발자가 직접 해줘야한다.

하지만 자바 개발자는 가상 머신이 제공한느 자동 메모리 관리 매커니즘 덕분에 메모리 할당을 직접 코딩하지 않아도, 메모리 누수나 오버플로 문제를 겪지 않는 다.

하지만 이와 관련된 문제가 생겼을 때 여기에 아예 무지하다면, 문제를 해결하기가 어렵다.

→ 가상 머신이 어떻게 메모리를 관리하는 지에 대해서 알아보자.

자바 가상 머신은 자바 프로그램을 실행하는 동안 필요한 메모리를 몇 개의 데이터 영역으로 나눠 관리한다.

**이 영역들은 각각 목적과 생성/삭제 시점이 있다.**

- 런타임 데이터 영역
    - 모든 쓰레드가 공유하는 데이터 영역
        - 메서드 영역
        - 힙
    - 스레드별 데이터 영역 - 스레드 프라이빗
        - **즉 쓰레드가 생성될 때 생성이 된다.**
        - 종류
            - 가상 머신 스택
            - 네이티브 메서드 스택
            - PC 레지스터

### RunTimeMemory 클래스 개요

```java
public class RunTimeMemory {
    // 메모리 크기 설정 (바이트)
    private static final int YOUNG_GEN_SIZE = 128;
    private static final int OLD_GEN_SIZE = 128;
    private static final int STACK_DEPTH = 10;

    // 런타임 메모리 영역
    private final YoungGeneration youngGen;
    private final OldGeneration oldGen;
    private final JVMStack stack;

    public RunTimeMemory() {
        this.youngGen = new YoungGeneration(YOUNG_GEN_SIZE);
        this.oldGen = new OldGeneration(OLD_GEN_SIZE);
        this.stack = new JVMStack(STACK_DEPTH);
        ReferenceTracker.initialize(youngGen, oldGen);

        // 초기화 메시지 출력
        System.out.printf("신세대(Young Generation): %d KB\\n", YOUNG_GEN_SIZE / 1024);
        System.out.printf("구세대(Old Generation): %d KB\\n", OLD_GEN_SIZE / 1024);
        System.out.printf("최대 스택 깊이: %d\\n", STACK_DEPTH);
    }
}

```

### 할당 로직

RunTimeMemory는 객체 크기에 따라 **자동으로** Young 또는 Old에 할당합니다.

**구현** (RunTimeMemory.java:44-65):

```java
public JVMObject allcate(JVMObject obj) {
    int remainingYoungSpace = youngGen.getAvailableSpace();

    // 조건 1: 객체 크기 > Young 잔여 공간
    if (obj.getSize() > remainingYoungSpace) {
        System.out.printf("[Issue] 객체 크기(%dB)가 신세대 잔여 공간(%dB)을 초과합니다. " +
            "구세대에 직접 할당합니다.%n", obj.getSize(), remainingYoungSpace);

        // Old로 직접 할당
        if (oldGen.allocate(obj)) {
            System.out.println("[Success] 객체 생성됨: " + obj.toDetailString());
            System.out.println("  → 대형 객체가 구세대에 직접 할당됨");
            return obj;
        }
        throw new RuntimeException("구세대 메모리가 가득 참");
    }

    // 조건 2: Young에 할당 가능
    if (youngGen.allocate(obj)) {
        System.out.println("[Success] 객체 생성됨: " + obj.toDetailString());
        System.out.println("  → Eden 영역(신세대)에 할당됨");
        return obj;
    }

    throw new RuntimeException("Eden 영역이 가득 함");
}

```

**할당 흐름도**:

```
객체 생성 요청
    ↓
객체 크기 > Young 잔여?
    ├─ Yes → Old로 직접 할당 (대형 객체)
    │         ↓
    │      성공? → 반환
    │         ↓ No
    │      예외 발생
    │
    └─ No  → Young (Eden)에 할당
              ↓
           성공? → 반환
              ↓ No
           예외 발생

```
