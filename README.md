## JVM 밑바닥까지 파헤치기: 콘솔 기반 GC 시뮬레이터

### 프로젝트 개요 (What & Why)

이 프로젝트는 자바 가상 머신(JVM)의 핵심 내부 메커니즘을 이론 학습에 그치지 않고 직접 구현하고 실험하기 위해 3주 동안 몰입하여 제작한 콘솔 기반 시뮬레이터입니다.

'JVM 파헤치기' 도서를 참고하여, JVM의 메모리 구조와 가비지 컬렉션(GC) 과정을 실제 코드 실행 로그를 통해 경험할 수 있도록 설계했습니다.

직접 코드를 실행하고 로그를 따라가며 JVM이 어떻게 움직이는지를 경험해 보시길 추천합니다.!

### 핵심 구현 기능

본 시뮬레이터는 실제 JVM의 Young/Old Generation GC 흐름을 모방하여 다음 메커니즘들을 구현했습니다.

| 구분 | 주요 구현 내용 |
| --- | --- |
| **메모리 영역** | Young Generation (Eden, Survivor 0/1), Old Generation |
| **객체 할당** | Bump Pointer 방식 할당, 대형 객체(Humongous Object) Old 영역 직접 할당 |
| **가비지 컬렉션** | Minor GC (Copying Algorithm) 및 Major GC (Mark-and-Compact Algorithm) 시뮬레이션 |
| **GC 메커니즘** | 객체 승격(Promotion), 나이(Age) 카운팅, **Remembered Set**을 통한 Old → Young 참조 추적 |
| **GC 전략** | Minor GC 임계값 (70%) 및 Major GC 임계값 (80%) 설정 및 트리거 구현 |
