YoonJVM은 메모리 사용률에 따라 자동으로 GC를 실행합니다.

### 6.1 Minor GC 자동 트리거

**조건**: Eden 사용률 >= 70%

```java
// YoungGeneration.java
public boolean isEdenFull() {
    double usage = (double) getEdenSize() / maxSize;
    return usage >= 0.7;
}

```

**YoonJVM에서의 사용**:

```java
public JVMObject createObject(JVMClass type) {
    objectId++;
    JVMObject obj = type.toJVMObject(objectId);

    try {
        runTimeMemory.allcate(obj);
        maybeTriggerAutoMinorGC("객체 생성");  // 자동 GC 체크
        return obj;
    } catch (RuntimeException e) {
        System.out.println("[Fail] 객체 생성 실패: 신세대 메모리 가득 차서");
        return null;
    }
}

private void maybeTriggerAutoMinorGC(String reason) {
    if (!runTimeMemory.isEdenFull()) {
        return;
    }

    logEdenUsage(reason + " 직전");
    gc.minorGC();  // 자동 Minor GC 실행
    System.out.println("자동 Minor GC 이후 메모리 상태:");
    runTimeMemory.printStatus();
}

```

### 6.2 Major GC 자동 트리거

**조건**: Old Generation 사용률 >= 80%

```java
// OldGeneration.java
public boolean isFull() {
    double usage = (double) currentSize / maxSize;
    return usage >= 0.8;
}

```

**Minor GC 후 자동 체크**:

```java
// GarbageCollector.java:135-138
if (allowMajorTrigger && oldGen.isFull()) {
    System.out.println("[경고] 구세대 사용량이 80%를 초과하여 Major GC를 자동 실행합니다.");
    majorGC();
}

```

### 6.3 트리거 임계값 선택 이유

| GC 종류 | 임계값 | 이유 |
| --- | --- | --- |
| Minor GC | 70% | Eden이 자주 차므로 여유 있게 설정 |
| Major GC | 80% | Old는 천천히 차므로 높게 설정 |
